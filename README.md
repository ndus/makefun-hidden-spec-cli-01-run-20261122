mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edit calls to a tree of text files, exactly as SPEC.md specifies.
Old lines are found at the first of three matching tiers (exact, trailing-whitespace-tolerant, fully whitespace-tolerant), and every change is written or none is.
It passes all 100 public practice checks (practice score 1000).
main.ts is the whole tool; runner.ts is the trial hand-over, kept as the kit has it.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
